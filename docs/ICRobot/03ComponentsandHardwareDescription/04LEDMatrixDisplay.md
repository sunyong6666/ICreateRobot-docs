# LED Matrix Display
## Introduction
The ICRobot robot's dot-matrix display features an 8 x 24 high-density pixel layout that supports white light display and brightness adjustment. Each dot position is programmable for control, enabling flexible and diverse content display. When the display is too long, the screen automatically scrolls from right to left. The display has a rich expressive ability, can display a variety of emoticons, status indicators, as well as user-defined patterns or text, to meet the diversified visual needs of different scenarios.

## Usage Instructions
| Device Status | Matrix Display |
| :---: | :---: |
| Powering On | Loading progress bar, boot-up animation |
| Initial Interface/Download Mode | Default Eyes |
