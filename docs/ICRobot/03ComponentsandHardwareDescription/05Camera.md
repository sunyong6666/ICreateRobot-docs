# Camera
## Introduction
<font style="color:rgba(0, 0, 0, 0.9);">The robot is equipped with a camera that supports UXGA resolution, has automatic functions such as AEC, AGC and AWB, and is capable of outputting multiple data formats. The camera is compact and powerful and can help students learn skills such as image recognition and target tracking.</font>

## Usage Instructions
Can be programmed to control the camera to turn on and off, etc. Refer to the block guide for specific programming instructions.
