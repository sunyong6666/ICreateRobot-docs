## Software-Related Issues

## Robot issues persist after firmware upgrade via “ICreateCode.exe”

* It may be that the in-app firmware has not been updated, please try to update the software application, refer to Software Installation.

## After the computer goes black screen and restarts, the communication between the robot and the computer fails, such as: the program cannot control the robot, the computer cannot obtain the return data, etc.

* Possible Causes and Solutions:
* Some system services may be disabled during sleep mode.
* Set the PC screen to stay awake during use. Navigate to: Settings ➡️ System ➡️ Power ➡️ Screen and Sleep to disable sleep and screen timeout options.

## STA mode network connection failure

* Possible Causes and Solutions:
* The mobile hotspot may be set to 5GHz. Please ensure it is set to 2.4GHz. Refer to Connection Method / Station Mode (STA).
* Check whether the computer has a wireless network card. Keep the mobile hotspot enabled during the process.

## Device name not displayed in AP mode

* Possible Causes and Solutions:
* The computer may not have refreshed the network list. Go to Settings ➡️ Network \& Internet ➡️ WLAN, turn it off and then back on, refresh the network list, then return to the software to reconnect.Refer to Connection Method / Access Point Mode (AP).
* Check whether the computer has a wireless network card and ensure WLAN is enabled.

## COM port not found during firmware switch

* Possible Causes and Solutions:
* Check if the USB cable is functioning properly; try using a different one.
* Check whether the USB port on the computer is damaged; try a different USB port.
* If the computer lacks the necessary serial drivers, install the appropriate driver.
