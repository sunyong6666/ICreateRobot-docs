# Programming Remote Controller Changelog
| ** Version  ** | ** Optimization Details  ** | ** Update Date  ** | ** Remarks  ** |
| :---: | --- | :---: | --- |
| V1.4.1 | Optimized the timing intervals between modules. | 2025.8.6 |  |
| V1.4.0 |  Fixed an issue where the light did not turn on after executing certain blocks in Loop Mode.   | 2025.5.22 |  |
| V1.4.0 | Integrated the Standard Version and Loop Memory Version programs.<br/>The mode can be switched using the debugging software.<br/>After switching modes, the remote controller saves the current mode.<br/>In Loop Mode, both Loop Blocks and Memory Blocks are supported. “Until” blocks are not supported.<br/>Memory Blocks cannot store sensor blocks.<br/>Loop Mode differs from Standard Mode in terms of operation. Please select the appropriate mode according to your requirements. | 2025.2.15 | Requirements:<br/>+ Programming software version V1.2.7 or later is required.<br/>+ No specific main controller is required. |
| V1.2.0 | Added communication commands for the Voice Prompt Module.   When a Voice Prompt Module is connected to the Controller:   a. The remote controller announces the corresponding block name each time a block is inserted.   b. When the Start button is pressed, the Voice Prompt Module announces “Start Execution”, plays the name of each corresponding module being executed, and then announces “Execution Completed”.<br/>Optimized the interval between expression and sound commands. | 2024.06.16 |  |
